# Wilfrid Labs

**Exploring software engineering, computer graphics, low-level computing, machine learning, and interactive visualization.**

Welcome to my personal engineering lab, a space for technical projects, experiments, and continuous learning.

My background is in software engineering, computer graphics, and real-time technologies, with professional experience at Silicon Studio and Unity.

I'm particularly interested in understanding computing systems across the entire technology stack, from semiconductor technologies and processor architectures to high-performance software, AI infrastructure, and machine learning applications.

This organization brings together my current explorations and selected work from my earlier GitHub accounts.

## Selected engineering projects

### Computer graphics & numerical algorithms

**[RGB to Spectrum](https://github.com/wip-/RgbToSpectrum)** | *[2014]*

A C# application illustrating RGB-to-spectrum conversion using Brian Smits' algorithm, including spectral power distribution filtering.

**Topics:** Computer graphics, numerical methods, color science, C#

### Real-time rendering & GPU investigation

**[Unity MSAA Pattern](https://github.com/Wilfrid-Unity/unity-msaa-pattern)** | *[2020]*

A Unity application for detecting and visualizing multisample anti-aliasing sample positions, using GPU sampling and shader techniques.

**Topics:** GPU programming, real-time rendering, MSAA, Unity
